# Third-party integrations

GraviStudio does not vendor these projects. The initializer installs skills or clones repositories from their upstream sources so their licenses remain separate.

| Integration | Purpose | Upstream license/status |
|---|---|---|
| latent-spaces/brag | Product/launch video skill | Check upstream repository at install time |
| heygen-com/hyperframes | Programmatic motion/video skills | Free/open-source; check upstream repository at install time |
| artbyjazi/autoclip | Long video to shorts | MIT |
| FujiwaraChoki/supoclip | Alternative short-form clipper | AGPL-3.0 |
| n0-space/openmontage | Agentic long-form video | AGPL-3.0 |
| gskfilmmaker/personalive | Experimental portrait animation | Research-oriented; inspect upstream LICENSE before use |
| Openverse | Open-content asset discovery | Asset licenses vary per item; provenance is recorded |
| Iconify | Open vector/icon discovery | Icon-set licenses vary; inspect metadata when required |

Always re-check the installed upstream version and license before commercial distribution.
