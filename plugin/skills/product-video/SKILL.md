# Product video

1. Inspect repository/site/product materials before searching external media.
2. Capture real UI/screens, feature states, logos and brand tokens where available.
3. If `/brag` is installed, use it as the primary launch-video workflow; use HyperFrames for custom motion/composition.
4. Do not invent product features or fake screenshots. Every claim must be supported by the supplied project/site.
5. Missing lifestyle/background visuals go through `/asset-agent`.
6. Render requested aspect ratio and run `/video-qc`.
